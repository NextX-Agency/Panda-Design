# Panda — website (conceptpreview)

Statische one-pager voor Panda, creatieve studio in Paramaribo. Geen build-stap.

- `site/` — de website (HTML, CSS, JS). Dit is de Vercel root directory.
- `docs/PREFLIGHT.md` — controle vóór de bouw en de oordelen.
- `docs/CONTENT-REGISTER.md` — status van tekst en media.
- `docs/VERIFICATIE.md` — wat is getest.
- `docs/PUBLICATIE.md` — wat nodig is voor productie.

Lokaal bekijken: `cd site && python3 -m http.server 4173`.

Status: **concept**. Gearceerde vlakken en `[…]`-teksten zijn layoutplaatsen. Niet naar productie zonder `docs/PUBLICATIE.md`.
